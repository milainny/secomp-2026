# sECOMP 2026

Site estático da Semana da Computação 2026. A programação é apresentada por dia e funciona sem instalação de dependências.

## Publicação

O workflow em `.github/workflows/deploy-pages.yml` publica o conteúdo no GitHub Pages a cada push para a branch `main`. No GitHub, abra **Settings → Pages** e escolha **GitHub Actions** como fonte de publicação.
